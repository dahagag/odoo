Sales Methodology, Explained

What the custom crm.methodology addon does, why it exists, and exactly how it differs from stock Odoo 19 CRM.

Intended Learning Outcomes

  • Name the core framework of each methodology the addon can model.
  • Explain what problem each methodology claims to solve.
  • Identify which methodologies are pre-seeded in the demo data.

TL;DR

The crm.methodology addon lets a Sales Manager define named qualification frameworks — MEDDIC, Sandler, or an in-house one — and attach them per client.

For consultants None of this touches the kanban pipeline.
